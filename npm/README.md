# Melange CLI

Official npm distribution of the [Melange CLI](https://github.com/zetic-ai/melange-cli).

```sh
npm install -g @zetic-ai/melange-cli
melange version
```

The package downloads the matching signed GitHub release for the current
platform and verifies its SHA-256 checksum before installation. Supported
targets are macOS, Linux, and Windows on x64 or arm64.
